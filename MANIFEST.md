# Submission Package Manifest

This package contains:

- `README.md` — project overview and scope.
- `docs/WORKFLOW.md` — step-by-step GitHub-ready lab workflow.
- `docs/explanation.md` — required 4–5 line explanation.
- `commands/command-history.txt` — command sequence and execution-history template.
- `evidence/README.md` — evidence instructions.
- `evidence/final-ls-laR.txt` — placeholder for real final recursive listing output.
- `evidence/ownership-observation.txt` — optional ownership observation template.
- `.gitignore` — prevents accidental local/editor files and shell history from being committed.

No execution evidence has been fabricated. Populate the evidence files from the actual Kali Linux environment before submission.
