# Required 4–5 Line Explanation

`chmod` changes the permission mode of a file or directory, controlling access for the owner, group, and others.

`ls -l` displays a detailed directory listing, including permissions, ownership, size, and timestamps.

`useradd` creates a new Linux user account and can be used with options to create a home directory and specify the user's shell.

In this task, `targets.txt` is assigned owner read/write, group read-only, and no permissions for others (`640`).

The commands are used together to demonstrate controlled user access, file organization, permissions, and ownership.
